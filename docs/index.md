# Bienvenido

Este sitio reúne el material de apoyo utilizado durante el taller, incluyendo contenidos teóricos, prácticas guiadas, ejemplos de código, recursos complementarios y el proyecto integrador que se desarrollará a lo largo de las sesiones.

La intención es proporcionar una introducción práctica al desarrollo de aplicaciones embebidas modernas utilizando MicroPython y ESP32, integrando conceptos de sensado, actuación, comunicación inalámbrica y plataformas IoT.

A lo largo del taller se abordarán aspectos relacionados con la programación de microcontroladores, adquisición de datos, control de dispositivos, protocolos de comunicación y arquitecturas distribuidas comúnmente utilizadas en aplicaciones IoT, Edge Computing y Sistemas Ciberfísicos.

---

## ¿Por qué MicroPython?

MicroPython es una implementación ligera de Python diseñada para ejecutarse en microcontroladores. Su facilidad de uso, capacidad de prototipado rápido e integración con tecnologías IoT lo han convertido en una alternativa atractiva para el desarrollo de aplicaciones embebidas modernas.

Entre sus principales ventajas destacan:

- Desarrollo rápido de prototipos.
- Código más legible y mantenible.
- Acceso directo a periféricos del hardware.
- Integración sencilla con protocolos de comunicación.
- Amplio soporte para plataformas ESP32.

## Metodología de trabajo

Cada tema combinará una breve introducción conceptual con actividades prácticas orientadas a la construcción progresiva de una aplicación funcional.

Durante el taller se utilizarán dispositivos ESP32 y MicroPython para implementar ejemplos relacionados con adquisición de datos, actuación, comunicación inalámbrica y monitoreo remoto.

## Proyecto Integrador

Los conocimientos adquiridos durante las sesiones serán aplicados en un proyecto integrador que permitirá combinar sensado, actuación, comunicación entre dispositivos y supervisión remota dentro de una misma solución.
